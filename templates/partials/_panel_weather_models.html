How weather models work

What each part of this page shows and how to use it

The big picture

Weather agencies run computer simulations of the whole atmosphere several times a day. This page takes two of them for free, reads the forecast at the plant's location, and turns it into an hourly MW curve.

GFS + ECMWF → sunlight, cloud, temperature → PV model → MW per hour → Blend

  • NOAA GFS (USA): hourly steps, 3 days ahead.
  • ECMWF IFS (Europe): 3-hourly steps, 2½ days ahead. Usually the more accurate of the two. Its steps are split into hours using the shape of a clear-sky day, so each 3-hour total is kept.
  • Both use a grid of about 28 km × 28 km. They show the general weather over the area, not single passing clouds.

Model runs & downloading

The line under Model forecast shows each model's run time (UTC), when its forecast started, and when this server downloaded it.

  • New runs come out about every 6 hours. The page downloads fresh data automatically once the saved data is more than 6 hours old.
  • Download latest runs forces this now. It takes about 3–5 minutes in the background.
  • If one model fails to download, its last good run stays on screen with "showing previous run".

Forecast day

Lists every local day that at least one model covers for all 24 hours. By default it picks tomorrow, the day you usually nominate for. Days further out have only GFS, because ECMWF stops sooner, and are less reliable.

Inverters available

Use this when some inverters are tripped, under maintenance or otherwise offline. Every MW figure on the page (charts, KPIs, table and the copied blend values) is scaled by available ÷ installed, and so is the AC limit.

  • Example: 160 of 167 available → 95.8% of the plant, so the AC limit drops from 50 MW to about 47.9 MW.
  • Changing the number previews the result straight away. Press Save for everyone so all users (and later visits) use it. All online resets to the full count.
  • This assumes each inverter carries an equal share of the panels. If the offline inverters are larger or smaller than average, adjust the number to match the lost capacity.
  • The installed total is set as ARECO_PLANT_INVERTERS in App settings.

Blend energy

The day's total expected generation (MWh) from the blend: the hour-by-hour average of all models that cover the full day. Averaging two independent models usually beats either one alone, because their errors partly cancel out.

Blend peak

The highest single hour in the blend. If it reaches the AC limit, the plant is expected to clip (the inverters hit their maximum) around midday.

GFS / ECMWF energy & disagreement warning

Each model's own daily total. Compare them to judge confidence:

  • Close together: settled weather; the forecast is more trustworthy.
  • 20% or more apart: an amber warning appears. The weather is hard to predict (storms, fast-changing cloud), so expect larger errors. Consider a more cautious nomination and watch the satellite on the day.

Daytime cloud (avg)

Average forecast cloud cover over daylight hours, across both models. It's a quick guide to how cloudy the day looks. Note that thin high cloud can read high here but block only a little sunlight, so trust the irradiance chart for MW.

Plant output MW chart

  • Blend: the recommended curve.
  • GFS / ECMWF: each model's own MW forecast.
  • Clear-sky (dashed grey): what the plant would make with no clouds. The gap below it is the expected cloud loss.
  • AC limit (dotted red): the inverter cap. Output can't go above it.

Hours are hour-ending in local time, the same as the nomination: 13 means 12:00–13:00.

Irradiance & cloud chart

Irradiance (GHI, W/m²) is how much sunlight reaches the ground, and it is what drives MW. The dashed line is a cloudless sky. The shaded bars are each model's cloud cover % (right axis).

Use it to see why output drops. For example, irradiance falling after 13:00 while cloud bars rise usually means afternoon thunderstorm build-up.

Hourly table

The numbers behind the charts. G/E columns show GFS / ECMWF side by side. Temperature is the average of both models.

Copy blend MW (24 values) copies hours 01–24 as one value per line, ready to paste into a nomination or the RTD (MW) column.

Clouds near the plant (satellite)

Live Himawari-9 imagery, updated every 10 minutes and about 30–60 minutes behind real time. Rings mark 25 km and 50 km from the plant.

  • Visible: clearest view of clouds in daytime.
  • Infrared: works at night; bright white means tall, cold storm clouds.
  • Air mass: highlights large weather systems.

Press Play to see which way clouds are moving and whether they're heading for the plant. This helps with intraday changes the models can't resolve.

How sunlight becomes MW

MW = DC MWp × GHI/1000 × PR × temp. loss (capped at AC max)

  • PR (performance ratio) covers all plant losses: wiring, dirt, inverters, panel angle.
  • Temperature loss: panels lose about 0.4% of output per °C above 25 °C.
  • The plant settings are shown in the note at the bottom of the page. To change them, use ARECO_PLANT_DC_MWP and ARECO_PV_PERFORMANCE_RATIO in App settings.

Calibration: python -m app.services.pv_calibration compares the plant's actual output (from uploaded MQ / compliance files) with NASA satellite sunlight and finds the PR that best fits this plant. Add --write to save it.

Tips & limits

  • Accuracy is best for tomorrow and drops for each day further ahead.
  • Models know how cloudy the area will be, not exactly when a cloud passes. Expect hour-to-hour misses on patchy-cloud days even when the daily total is close.
  • Re-check after the next run (every 6 hours). If the curve shifts a lot between runs, that is another sign of uncertainty.
